# 旅行社獲客網站｜實作與驗收紀錄

驗證日期：2026-10-19。對應 PRD v0.2、CCI、SIPOC。網站入口為 `../index.html`，本機預覽為 <http://127.0.0.1:8766/>，啟動方式見 [README](../README.md)。這是教學示範，不是正式旅行社商品、名單收件或公開上線。

## 完成內容

原生 HTML、CSS、JavaScript；深綠、奶油白、暖橘品牌介面。完成首頁與特色、四項偏好、選填日期／備註、9 筆本地方案、最多 3 筆推薦、來源詳情、方案比較、諮詢候選、純文字複製／下載／清除，以及沿用本地宣傳影片。沒有帳密、Supabase、付費 API 或外部追蹤器。

所有價格、天數、標題與每日提綱明示模擬。圖片是 AI 情境圖，並非對應景點實拍。研究來源僅支持景點特色或活動公告，不支持模擬報價。活動會隨瀏覽器當下的台北日期檢查，不讓過期資料冒充可用商品。

## 實際驗證環境與證據

- Windows、本機 Microsoft Edge，以 Playwright 驅動真實瀏覽器引擎；沒有用假剪貼簿取代成功案例，實際寫入及讀回瀏覽器剪貼簿。
- [主要測試腳本](../.build/test-site.mjs)：16 組通過紀錄，含純函式規則及瀏覽器流程。
- [錯誤／操作測試腳本](../.build/test-site-errors.mjs)：4 組通過紀錄，包含實際中止媒體請求、重試恢復與鍵盤操作。
- [主要執行結果](../outputs/site-qa/test-results.json)、[補充執行結果](../outputs/site-qa/additional-results.json)。組數為測試情境群，不等同 PRD 驗收項目數。
- [桌面首頁](../outputs/site-qa/desktop-home.png)、[桌面完整畫面](../outputs/site-qa/desktop-full.png)、[平板](../outputs/site-qa/tablet-full.png)、[手機](../outputs/site-qa/mobile-full.png)、[橫向](../outputs/site-qa/landscape-full.png)、[200% 根文字尺寸](../outputs/site-qa/text-200.png)。桌面首頁及手機／平板的局部畫面已人工檢視；橫向與 200% 尺寸有截圖及溢出檢查，未逐區完成人工視覺審查。

## 修正與未驗證事項

測試過程修正了表單按鈕 ID 與原生 reset 方法的名稱衝突、媒體備援新增時的語法問題，以及媒體在腳本初始化前失敗卻沒顯示重試的情況。修正後主要測試及補充測試均通過；最後的早期媒體失敗修正已由補充測試確認。

未驗證：實體 iOS／Android、Safari／Firefox、螢幕閱讀器、完整 Tab 順序與整站對比度稽核、實體手機剪貼簿權限、官方來源現況、正式旅遊價格／交通／可訂狀態、公開部署及真實旅行社收件。這些項目沒有被宣稱完成。暫無上述已執行測試中的未解決失敗。

本機伺服器只綁定 127.0.0.1；關閉工作環境後網址可能失效，請依 README 重新啟動。需求單只在本機產生，**尚未傳送給旅行社**。
