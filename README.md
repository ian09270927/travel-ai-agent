# 島嶼之間｜旅行社獲客網站教學示範

原生 HTML、CSS、JavaScript。依旅伴、每人整趟預算、天數及風格篩選本地示範方案，再比較並複製諮詢需求。無需安裝網站套件、登入、Supabase 或付費 API。

**所有行程、價格與天數都是教學模擬，非正式旅遊商品或保證報價。品牌為示範。** 景點特色與活動公告另附官方來源；圖片為 AI 情境示意，非景點實拍。來源查詢基準日為 2026-10-19，網站不即時更新來源。

## 開啟本機預覽

在此專案資料夾開啟 PowerShell，執行：

```powershell
python -m http.server 8766 --bind 127.0.0.1
```

Windows 若使用 Python Launcher，可改用：

```powershell
py -m http.server 8766 --bind 127.0.0.1
```

瀏覽 <http://127.0.0.1:8766/>。若同一個預覽已在執行，直接開網址即可；若連接埠被其他服務使用，可換成 8767，網址也一起更換。關閉自己啟動的伺服器可按 Ctrl+C。

請使用本機 HTTP。直接雙擊 index.html 的 file:// 模式通常會阻擋 JavaScript 模組與 JSON 讀取，無法完成推薦；本網站會提供資料錯誤提示。

## 課堂操作

1. 選「親子、1 天、預算 2800、自然生態」，推薦「台北都市生態示範遊」。
2. 改為預算 2799，舊結果會失效；重新推薦後沒有符合方案。
3. 改為預算 3000、文化藝文，推薦「八里親子考古示範遊」。
4. 展開詳情看研究來源及待確認事項，加入比較、選為諮詢候選。
5. 在需求單區複製或下載文字。此流程**沒有傳送給旅行社**，也沒有建立訂位。

音樂活動方案必須選日期，且出發日期及旅程活動日須符合公告期間。日期判斷使用瀏覽器當下的台北日期；活動過期後不再推薦。測試腳本使用固定測試時鐘，不修改產品時鐘。

## 檔案與修改位置

| 檔案 | 用途 |
|---|---|
| `index.html` | 首頁、表單、比較、影片、需求單及說明 |
| `site/styles.css` | 品牌視覺、手機與平板排版 |
| `site/app.mjs` | 本地讀檔、介面狀態、複製／下載與錯誤備援 |
| `site/recommendation.mjs` | 資料驗證、日期檢查、排序、需求文字等純函式 |
| `site/data/mock-plans.json` | 9 筆獨立示範方案，保留 mock 標示 |
| `research/` | 既有真實研究原檔，本次未覆寫 |
| `video/` | 沿用已完成的本地情境圖與宣傳片 |
| `docs/TEST-REPORT.md` | 實際驗收證據與未測試範圍 |

不要把示範價格改寫成官方報價。若新增活動方案，須設定研究關聯及 `event_requirements` 的 `research_id`、`day_index`；資料錯誤的方案會排除，重複 ID 的兩筆都會排除。

## 隱私及測試

選擇與備註只放當次頁面記憶體；重新整理或「清除需求」會重設。不要填真實聯絡、證件或健康資料。只有主動點擊才會寫入剪貼簿或下載檔案。官方來源連結由使用者自行開啟。

開發測試使用 `.build/test-site.mjs` 與 `.build/test-site-errors.mjs`，需要 Playwright 與本機 Edge；網站本身不需要這些測試套件。此環境的測試腳本使用 Codex 隨附 Node 與 Playwright 路徑，移至其他電腦時需調整腳本的模組位置及預覽連接埠。

既有 CCI、SIPOC、PRD 保留需求制定時的版本狀態；本次實作狀態請看驗收紀錄。網站尚未公開部署，未提供真實名單收件服務。

## GitHub 課堂提交

建議儲存庫名稱：`travel-ai-agent`。先完成本地 Git Commit，再確認 GitHub 的擁有者、儲存庫名稱、公開／私人設定及完整檔案清單，最後才建立或上傳遠端。提交 GitHub 不等於網站已部署。

**不要上傳帳號密碼、API Key、存取權杖、私鑰或其他秘密。** `.gitignore` 只阻止未追蹤檔案，無法移除已提交的秘密；若秘密曾提交，應先撤銷／輪替，再處理歷史紀錄。請勿將真實值寫入範例設定檔。

此專案第一版不需要任何 API Key。版本管理保留網站程式、模擬資料、研究與規格、簡報、網站需要的 AI 圖／最終影片／封面，以及驗收證據。排除中間影片、WAV／MP3 製作音訊、建置暫存、日誌、依賴、環境設定及憑證；排除只是不上傳，沒有刪除本機原檔。

本地 Commit 後，可先檢查：

```powershell
git status --short
git log -1 --oneline
git ls-tree -r --name-only HEAD
git remote -v
```

遠端目標及提交清單記錄於 [首次提交檢查](docs/GIT-HANDOFF.md)。確認前不執行 `git push`。學員請使用自己的 Git 身分及 GitHub 帳號；第一次提交會包含 Git 設定的作者姓名與 Email，公開前請確認符合自己的隱私偏好。
