# 臺灣旅遊情報｜來源與查證紀錄

查詢日期：2026-10-19（Asia/Taipei）

## 範圍與方法

共 9 筆：6 個景點、3 項活動。涵蓋臺北、新北、南投、嘉義、臺中、屏東，供親子、情侶及熟齡推薦示範使用；不是全臺完整清單。

本次可連網，全部為真實官方來源研究，沒有模擬資料。優先開啟交通部觀光署「觀光多媒體開放資料」明細頁，再查官方活動資訊。這份 JSON 是研究員整理的衍生資料，並非直接下載 API 的原始回應。部分頁面提示 JavaScript 功能受限，但所列事實已由可讀正文核對。

## 欄位定義

- `features`：官方介紹摘要，不直接複製大段原文。
- `suitable_audiences` 與 `audience_assessment`：研究判斷及適用條件，並非官方認證。熟齡不等於行動不便，也不保證全程無障礙。
- `activity_dates`：僅活動填入官方公告期間；常設景點以 null 加「不適用」說明，不編造全年活動日期。
- `price`、`opening_hours`、`transport_schedule`：本版未完成營運查證，統一保留 null；不等於免費、停業或無交通。即使部分開放資料有相關文字，也未作為本版已核實營運資料提供。
- `source.updated_at`：來源明示更新日；未取得則 null。查詢日不能代替更新日。
- `is_mock`：全部 false。JSON 解析與欄位檢查不能代替官方資料更新或現場驗證。

## 差異、限制與排除紀錄

1. 搜尋「北投溫泉博物館」時，搜尋摘要指向 `attraction_379000000a_000033`；實際開啟卻顯示「社子島環島與二重疏洪道自行車道」。名稱不一致，排除該筆，不採搜尋摘要補寫。問題頁：[實際開啟網址](https://media.taiwan.net.tw/zh-tw/portal/travel/details/attraction_379000000a_000033)。
2. S03 海生館來源更新日為 2024-10-15，僅採基本展館特色，不採歷史排名、現有動物陣容或可報名名額；出發前須查館方最新消息。
3. S04 向山平台資料標示「需入場相關費用」，但金額空白；不得自行推定免費。未以來源的一般營運時間保證旅行日開放。
4. S05 十三行博物館的來源資料類型為「旅遊服務站點／借問站」；本資料依實際旅遊內容歸為景點，保留原始 ID，避免冒稱原始景點資料集分類。
5. S01 中文頁可讀景點介紹，但本次未取得可靠的更新日期，故保留 null。
6. 研究員對親子、情侶與熟齡的判斷皆為有條件建議。北投文物館山坡動線、向山平台格柵、阿里山山區體力及活動人潮等限制已記錄在各筆資料。
7. 未進行現場、購票、交通班次、即時人潮或無障礙全路線驗證，亦未儲存原始網頁完整快照。
